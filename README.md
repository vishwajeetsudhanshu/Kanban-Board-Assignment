#  🗂️ Kanban Board – Task Management App

This is a simple and modern Kanban-style task management application. It helps users organize their tasks easily by dividing them into different stages. The interface is clean, responsive, and easy to use.

The app is built using React and TypeScript, and it supports smooth drag-and-drop functionality for managing tasks efficiently.



## Features

- **Homepage**: The homepage shows all tasks divided into three categories:

   - To Do

   - Doing

   - Done

- **📝 Task Cards**: Each task appears as a card displaying:

 - Task title

 - Task description

- **➕ Add Task**: Users can create a new task by filling out a simple form with:
 
  - Title

  - Description

- **✏️ Edit Task**: Tasks can be updated anytime. Users can modify:

   - Title

 - Description

- **🗑️ Delete Task**:Users can permanently delete tasks they no longer need.

- **🔄 Drag and Drop**: Tasks can be moved between To Do, Doing, and Done using drag-and-drop.
This makes updating task status fast and interactive.

## Installation 

1. Clone the repository to your local machine using the following command:
    ```
   https://github.com/vishwajeetsudhanshu/Kanban-Board-Assignment
   ```
2. Navigate to the `Frontend` directory:

   ```
   cd kanban-board
   ```

3. Install the required dependencies by running the following command:
    ```
   npm install
   ```
4. Finally, start the Frontend of the Application:
   ```
   npm start
   ```
5. Open your browser and visit `http://localhost:3000` to access the captivating world of TravelDiary.
